# navigation (cd, paths)

**Theoretical Recap** Navigating the Linux filesystem is a foundational skill for any security professional. Every file and directory in Linux lives within a single hierarchical tree rooted at /. Understanding how to move through this tree efficiently is essential when you are performing reconnaissance, examining log files, or tracing the footprint of an intrusion. Two types of paths exist. An **absolute path** always starts from the root (/), for example /etc/passwd or /var/log/syslog. It works regardless of your current location. A **relative path** starts from your current working directory, for example ../config or ./scripts/run.sh. The dot (.) refers to the current directory, and double dot (..) refers to the parent directory. The cd (change directory) command is your primary navigation tool. cd /etc moves you to /etc using an absolute path. cd logs moves you into a subdirectory called logs relative to where you are. cd .. moves you one level up. cd ~ or simply cd returns you to your home directory. cd - brings you back to the previous directory, a trick that saves time when toggling between two locations. Common mistakes include forgetting the leading slash when intending to use an absolute path, confusing . and .. in multi-level traversal, and using paths with spaces without quoting them. Always confirm your location with pwd after moving. Mini example: you are at /home/analyst. Running cd ../../etc is equivalent to running cd /etc from any location — you climbed two levels to reach / then entered etc. --- **Workshop...
