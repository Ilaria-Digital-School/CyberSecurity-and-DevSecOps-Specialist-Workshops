# Install virtualisation software on your computer

Theoretical Recap: Virtualisation Fundamentals Virtualisation is the process of creating a software-based, or virtual, representation of a computer system. This virtual machine operates like a physical computer, with its own operating system and applications, but it runs on a host machine. The key piece of software enabling this is called a hypervisor or virtualisation platform. It manages the resources of the host hardware and allocates them to the virtual machines, ensuring isolation between them. This isolation is the core principle that makes virtualisation ideal for your cybersecurity lab: experiments are contained, and mistakes cannot affect your main system. A clear mental model is to think of the hypervisor as a manager that creates and runs separate, walled-off rooms (virtual machines) inside a large building (your host computer). Each room is independent, with its own utilities. Common mistakes include installing the wrong version of the software for your host operating system, neglecting to enable hardware virtualisation support in your computer's BIOS, or allocating excessive resources to a single virtual machine, which can starve your host system. For a small numeric example: if your computer has 16 GB of RAM, you might allocate 4 GB to a Windows virtual machine, 2 GB to a Linux virtual machine, and keep the remaining 10 GB for your host operating system to run smoothly.
