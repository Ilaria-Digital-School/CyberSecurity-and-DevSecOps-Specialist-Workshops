# Move around the directory tree and describe it

Theoretical Recap You have learned the Linux directory tree is a hierarchical structure for organizing files, starting from the root. The root directory is labeled with a single forward slash /. From there, branches descend to system directories like /bin and /etc, and further to user home directories like /home/username. This hierarchy is like an inverted tree where directories are the nodes. A key definition is the 'working directory', which is your current location. The 'parent directory' is one level above. The 'absolute path' describes a file's location from the root, beginning with /. The 'relative path' describes it from your working directory, which is more flexible for navigation. Your mental model should be a map you can explore and trace. A common mistake is confusing absolute and relative paths or misunderstanding the special symbols. The dot . represents the current directory. Two dots .. represent the parent directory. The tilde ~ represents your home directory. Another error is trying to move into files instead of directories. Consider a small numeric example: A file at /home/user/docs/report.txt has three directory levels from root. From your home directory (~), the relative path to it is docs/report.txt. From the root, the absolute path is fixed. Understanding this difference is essential for efficient navigation and scripting.
