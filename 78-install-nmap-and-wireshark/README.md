# Install nmap and wireshark

THEORETICAL RECAP Before any penetration test or network analysis, you need a reconnaissance toolkit. Two tools are foundational: nmap and Wireshark. Nmap (Network Mapper) is an active scanner: it sends crafted packets to hosts to discover live machines, open ports, running services, and sometimes operating system fingerprints. Wireshark is a passive packet analyzer: it captures and decodes traffic flowing through a network interface, letting you inspect protocols frame by frame. The mental model: nmap asks questions and reads answers (active, noisy, detectable), while Wireshark silently listens to everything that passes (passive, observational). They complement each other—nmap tells you what is exposed, Wireshark shows you what is actually being exchanged. On Linux you already know package managers (apt, yum/dnf) from your previous course, and you can identify open ports with ss/netstat. This workshop bridges those skills to security tooling. Common mistakes: installing outdated versions from a distro repository without checking, forgetting that Wireshark capture requires elevated privileges or membership in the wireshark group, and running nmap scans against systems you are not authorized to touch (this is illegal). Mini example: after installing, 'nmap -sV localhost' reveals services listening on your own machine, and cross-checking with 'ss -tulpn' confirms the same ports—demonstrating how active scanning correlates with local socket state.
