# Workshop: Port → service dictionary

**Theoretical Recap** A dictionary in Python is a data structure that stores key-value pairs, where each key is unique. Unlike lists, which use integer indices, dictionaries use meaningful keys to access values instantly — making them ideal for mapping relationships like port numbers to service names. The syntax is straightforward: `my_dict = {80: 'HTTP', 443: 'HTTPS', 22: 'SSH'}`. You access a value with `my_dict[80]`, which returns `'HTTP'`. You can iterate over a dictionary using `.items()`, which yields both key and value at each step: `for port, service in my_dict.items(): print(port, service)`. A common mistake beginners make is confusing a missing key error (`KeyError`) with an empty value. Always use `.get(key, default)` when you are not certain a key exists — for example `my_dict.get(8080, 'Unknown')` returns `'Unknown'` instead of crashing. Another frequent error is using mutable objects as keys; stick to integers or strings for port mappings. In a security context, this kind of mapping is foundational. When you scan a network with a tool like Nmap, you get a list of open ports. Being able to instantly translate port 3306 into 'MySQL' or port 21 into 'FTP' lets you prioritize your reconnaissance and understand your attack surface without looking up every port manually.
