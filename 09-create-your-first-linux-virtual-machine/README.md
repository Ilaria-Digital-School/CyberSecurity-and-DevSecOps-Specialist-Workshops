# Create your first Linux virtual machine

A virtual machine (VM) is a software-based emulation of a computer system. It runs an operating system and applications just like a physical machine, but is isolated within a host computer. This isolation is a core cybersecurity principle, creating a safe sandbox lab where you can experiment without risk to your real system. For instance, a penetration testing lab requires this precise isolation to perform attacks ethically on designated targets. Thinking of a VM as a computer-in-a-box is a useful mental model. Common mistakes include allocating excessive RAM or CPU cores to the VM, starving the host OS, or forgetting to disable shared folders or drag-and-drop features that can break isolation. Another typical error is selecting the wrong network adapter mode, preventing the VM from connecting to your lab network or the internet. A mini example: if your host has 16GB of RAM, you might allocate 4GB to the VM, leaving 12GB for the host, and provide 2 CPU cores from a total of 8. The objective of this workshop is to translate the theoretical concepts of virtualisation and lab safety into a tangible, functioning system. You will create your first Linux virtual machine, establishing the foundational tool for all your subsequent hands-on cybersecurity training. Your mission is to build a dedicated, isolated environment where you can safely learn administration and security techniques, directly applying the principles from your ethical hacker charter and lab setup lessons.
