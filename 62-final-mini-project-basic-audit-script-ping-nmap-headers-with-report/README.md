# Final mini-project: basic audit script (ping, nmap, headers) with report

## Project Overview This final mini-project consolidates everything you have practiced throughout the chapter: port scanning with Nmap, HTTP header analysis with the Requests library, date/timestamp manipulation, output formatting (text, CSV, JSON), and secure scripting best practices. You will build a single, cohesive Python audit script that performs three reconnaissance tasks on a target — ping check, Nmap port scan, and HTTP header inspection — then generates a structured report in multiple formats. This project is deliberately end-to-end: it mirrors the reconnaissance phase of a real pentest engagement on an authorized perimeter and produces the kind of deliverable a junior DevSecOps specialist would hand to a team lead. --- ## Context You are a junior security analyst assigned to perform a basic automated audit on a test machine (localhost or a lab VM you control). Your manager asks you to deliver a Python script that can be run from the command line, that requires no manual intervention once launched, and that outputs a clean report. The report must be readable by both humans (plain text) and machines (CSV, JSON) for potential integration into a CI/CD pipeline. --- ## Skills Validated - Writing a modular, secure Python script following best practices (shebang, file permissions, no hardcoded secrets) - Automating ping-based host availability checks via subprocess - Wrapping Nmap to scan a port range and capturing XML output for parsing - Sending HTTP(S) requests and extracting/evaluating security-relevant headers (e.g., X-Frame-Options, Content-Security-Policy, Strict-Transport-Security) - Generating timestamped reports in text, CSV, and JSON formats...
