# Mini-project step 1: Nmap wrapper (runtime + XML capture)

## Mini-project: Nmap Wrapper — Runtime & XML Capture ### Project Overview In this first mini-project step, you will build a Python wrapper around the Nmap network scanner. Rather than running Nmap manually from the terminal, your script will launch Nmap programmatically, capture its output in real time, and parse the resulting XML report to extract structured data. This project bridges everything you have practiced so far — port scanning with sockets, regular expressions for log parsing, data structures (lists, dictionaries), and date/time handling — and applies them inside a realistic security automation workflow. The end goal is a reusable, scriptable tool that a DevSecOps specialist would actually use in a reconnaissance pipeline. ### Why This Matters Professionally Nmap is the industry-standard tool for network reconnaissance. Security engineers rarely run it interactively for large-scale or repeated assessments; instead, they wrap it in scripts that automate scanning, archive results, and feed data into reporting or CI/CD pipelines. Mastering this pattern is a direct prerequisite for the pentest and DAST phases covered later in the course. ### Scope - Target environment: local lab only (localhost, 127.0.0.1, or a dedicated VM on your local network). You must only scan hosts you own or have explicit written permission to scan. - Nmap version: 7.x or later, installed on your machine. - Python version: 3.8 or later. - No third-party Nmap Python libraries (e.g., python-nmap) are allowed for the core wrapper logic.
