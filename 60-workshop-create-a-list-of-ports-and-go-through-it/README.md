# Workshop: create a list of ports and go through it

**Theoretical Recap** In Python, a list is an ordered, mutable collection of items defined with square brackets: `my_list = [80, 443, 22, 8080]`. Lists are one of the most fundamental data structures you will use in security automation — for example, storing a set of ports to scan, a range of IP addresses, or a collection of known vulnerabilities. You iterate over a list using a `for` loop: `for item in my_list:`. You can also build lists dynamically using `list()` or the `range()` function (e.g., `list(range(1, 1025))` generates all ports from 1 to 1024). A common mistake at this stage is confusing `range()` (which produces a range object) with an actual list. Always remember that `range(1, 10)` does not print as a list unless you explicitly convert it. Another frequent pitfall is off-by-one errors: `range(1, 1025)` includes 1 but stops at 1024 — exactly what you want for well-known ports. In a cybersecurity context, iterating over a port list is the conceptual foundation of a port scanner. Before you can build anything more complex (using `subprocess`, sockets, or Nmap wrappers), you need to master constructing and traversing port lists programmatically. This workshop bridges your knowledge of data structures and the subprocess/OS scripting work you did in previous sessions.
