# Workshop: scan ports 20 to 25 of a local target

**Theoretical Recap** A port scanner is one of the most fundamental tools in a security professional's toolkit. In networking, a port is a logical endpoint for communication, identified by a number from 0 to 65535. When you attempt to connect to a port on a remote or local host, the host responds in one of three ways: it accepts the connection (port is open), it refuses it (port is closed), or it simply does not respond (port is filtered). Python's built-in `socket` module lets you programmatically attempt TCP connections to any IP/port combination and interpret the result. The core pattern is straightforward: create a socket object using `socket.socket(socket.AF_INET, socket.SOCK_STREAM)`, set a timeout with `socket.settimeout()` to avoid hanging indefinitely, then call `.connect_ex(host, port)` — which returns 0 on success and a non-zero error code otherwise. Wrap this in a loop over a range of port numbers, and you have a basic port scanner. Common mistakes at this stage include forgetting to close the socket after each attempt (leading to resource leaks), setting the timeout too high (making the scan very slow) or too low (causing false negatives on slow networks), and confusing `connect()` (raises an exception on failure) with `connect_ex()` (returns an error code). Also remember that scanning targets you do not own or have explicit permission to scan is illegal — always work on localhost or a dedicated lab environment.
