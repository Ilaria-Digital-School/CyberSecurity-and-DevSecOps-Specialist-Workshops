# First steps: pwd, ls, clear

**Theoretical Recap** Before diving into the hands-on tasks, let's consolidate the key concepts from the previous lesson on Linux terminal fundamentals. The Linux terminal (also called the shell or command-line interface) is your primary tool as a security professional. Unlike graphical interfaces, the terminal gives you direct, granular control over the system — essential for penetration testing, log analysis, and secure deployments. Three commands form the absolute foundation of any terminal session. `pwd` (Print Working Directory) tells you exactly where you are in the filesystem tree. Think of the Linux filesystem as an upside-down tree: everything starts at the root `/`, and directories branch outward. Losing track of your current location is a common beginner mistake that leads to operating on wrong files or directories. `ls` (List) displays the contents of a directory. Without arguments, it lists the current directory; with flags like `-l` (long format), `-a` (all files including hidden ones starting with `.`), or `-la` (combined), it reveals critical details such as permissions, ownership, file sizes, and hidden configuration files — all highly relevant in security contexts. `clear` simply cleans the terminal screen, improving readability during long sessions. Common mistakes: assuming you know your current directory without checking (`pwd` costs nothing), ignoring hidden files when auditing a system (always use `ls -la`), and confusing `clear` with actually deleting data (it only refreshes the display).
